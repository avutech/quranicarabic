# Lessons

- **I'rab provenance is mandatory.** Any i'rab text shown or stored must stay traceable to its book, author, source and exact ayah entry — per entry, not only per book. Translations must record the source entry and a hash of the Arabic they came from. Build pipelines must never drop these fields. (2026-10-03)
- **No paid API calls for bulk work** (OCR, translation) — use free/local tools or in-session agents. (2026-10-03)
