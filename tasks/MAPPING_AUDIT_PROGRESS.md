## Framework and repeatable commands

Run from the repository root:

```sh
python3 portal/mapping_audit.py
python3 portal/mapping_source_compare.py
python3 portal/mapping_progress.py
python3 portal/mapping_review.py queue 20
python3 portal/mapping_review.py case 2 akhfash:142-142
python3 portal/mapping_review.py verses 2 142-143
python3 portal/mapping_review.py status
```

`mapping_review.py vote FILE.json` validates frozen source/association hashes,
current Quran context, explicit translation mapping verdicts, canonical target
bounds and evidence. It supports cross-surah, disjoint, and introduction targets.
Two distinct reviewers must agree; disagreement and uncertainty escalate.
Agreements remain proposals, and the tool cannot apply them. Reviewer identity
and blinded context must be enforced by the orchestrator; labels alone cannot
prove independence. Queue status is deliberately conservative and does not
automatically import narrative first-review records as adjudicated decisions.

Detailed instructions: `tasks/MAPPING_AUDIT_FRAMEWORK.md`.
Continuation: `tasks/HANDOVER_CLAUDE.md`.
